# Lecture 06: Linear Models

MKTG 411 materials for introducing linear models, simulating a known
relationship, and analyzing customer spending.

- Slide source: `06 Linear Models.Rmd`.
- Rendered slides: `06-Linear-Models.html`; `index.html` is the matching
  GitHub Pages entry file.
- Student starter code: `06-starter-code.qmd`.
- Exercise and rubric: `Exercise 5 Solution.qmd` and its Word output.
- Data: `home_goods_customers.csv`, with `data_dictionary.pdf` and the editable
  `data_dictionary.md`.

View the slides at <https://cdbale.github.io/06-Linear-Models/#1>.

The current HTML files were rendered on October 5, 2026 and match each other.

slide source, render it explicitly and update both HTML files before publishing.
